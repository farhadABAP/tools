ABAP Dashboard Utility Tools

A suite of anonymized ABAP programs designed to inspect Data Dictionary structures, read database tables, and inject test data for SAP GUI dashboard development.

View on GitHub

Included Tools

1. Dictionary Inspector

zfc_show_dict_details.abap

Dynamically reads the SAP Data Dictionary to display technical configurations, field structures, and domain fixed values.

2. Data Reader

zfc_read_db_data.abap

Reads and displays the current contents of custom database tables in the SAP GUI list output.

3. Data Injector

zfc_inject_test_data.abap

Updates specific existing records and adds documentation notes for dashboard testing.
