🎯 Open-Book Exam Strategy: Do not waste time memorizing syntax. Your goal is to know what to search for and have boilerplate code ready to copy-paste. Use the search bar above (Ctrl+F / Cmd+F) to instantly find snippets during the exam.

Top 3 Time-Savers for the Exam

1. Master Joule

Joule is your best friend. Instead of typing a 50-line Behavior Definition, prompt Joule: "Generate a managed RAP behavior definition for ZI_MyEntity with draft enabled." Verify the output, tweak it, and move on.

2. Know the "Released" Rule

If the exam asks you to read from MARA, you cannot write SELECT * FROM mara. You must search SAP Help for "released CDS view for material" (e.g., I_Material) and select from that.

3. EML is Mandatory

You will likely need to read or modify data in an ABAP class. Memorize the READ ENTITIES and MODIFY ENTITIES boilerplate below. It's the #1 thing candidates forget the syntax for.

📄 Standard CDS View with Fiori Annotations

@EndUserText.label: 'My Custom Entity'
@Search.searchable: true
@AccessControl.authorizationCheck: #CHECK
define root view entity ZI_MyEntity
  as select from I_ReleasedSAPView
{
      @UI.hidden: true
  key MyKeyField,

      @Search.defaultSearchElement: true
      @UI.lineItem: [{ position: 10, label: 'Description' }]
      Description,

      @UI.lineItem: [{ position: 20, label: 'Amount' }]
      Amount,

      @UI.lineItem: [{ position: 30, label: 'Currency' }]
      Currency
}

🔗 CDS Association & Path Expression

define view entity ZI_MyEntity
  as select from I_MyBaseView
  association [0..1] to I_CompanyCode as _CompanyCode 
    on $projection.CompanyCode = _CompanyCode.CompanyCode
{
  key MyKeyField,
  CompanyCode,
  
  // Path expression to get data from associated view
  _CompanyCode.CompanyName as CompanyNameText
}

⚙️ Managed Behavior Definition (with Draft)

define behavior for ZI_MyEntity
  implementation in class zbp_i_myentity unique
  persistent table zmy_table
  draft enabled
{
  create;
  update;
  delete;

  field ( readonly ) MyKeyField;
  field ( mandatory ) Description;

  // Determination to set defaults on create
  determination setDefaults on modify { create; }
  
  // Validation to check data on save
  validation validateData on save { create; update; }
}
/* 📚 SAP Help: Search "RAP behavior definition syntax" */

📖 EML: READ ENTITIES (The most tested snippet)

" Read specific fields for specific keys
READ ENTITIES OF ZI_MyEntity IN LOCAL MODE
  ENTITY ZI_MyEntity
    FIELDS ( Description Amount )
    WITH VALUE #( ( MyKeyField = '12345' ) )
  RESULT DATA(lt_result)
  FAILED DATA(lt_failed)
  REPORTED DATA(lt_reported).

" Read ALL fields for ALL instances (use sparingly)
READ ENTITIES OF ZI_MyEntity IN LOCAL MODE
  ENTITY ZI_MyEntity
    ALL FIELDS
  RESULT DATA(lt_all_result).

✏️ EML: MODIFY ENTITIES & COMMIT

MODIFY ENTITIES OF ZI_MyEntity IN LOCAL MODE
  ENTITY ZI_MyEntity
    UPDATE FIELDS ( Description )
    WITH VALUE #( ( MyKeyField = '12345' Description = 'New Text' ) )
  REPORTED DATA(lt_reported)
  FAILED DATA(lt_failed).

" ALWAYS commit after modify in standalone classes
COMMIT ENTITIES
  RESPONSE OF ZI_MyEntity
  FAILED DATA(lt_commit_failed)
  REPORTED DATA(lt_commit_reported).

🚀 Executable Class (IF_OO_ADT_CLASSRUN)

CLASS zcl_my_test DEFINITION PUBLIC FINAL CREATE PUBLIC.
  PUBLIC SECTION.
    INTERFACES if_oo_adt_classrun.
ENDCLASS.

CLASS zcl_my_test IMPLEMENTATION.
  METHOD if_oo_adt_classrun~main.
    " Modern inline declaration
    DATA(lv_text) = |Hello ABAP Cloud|.
    
    " Output to console in BAS / ADT
    out->write( lv_text ).
    
    " Call your logic
    " NEW zcl_my_logic( )->execute( ).
  ENDMETHOD.
ENDCLASS.

🛡️ Modern Exception Handling (No SY-SUBRC)

METHOD process_data.
  TRY.
      " Your logic here
      DATA(lv_result) = calculate_something( ).
      
    CATCH cx_root INTO DATA(lx_error).
      " Log error or raise custom exception
      RAISE EXCEPTION TYPE zcx_custom_error
        EXPORTING
          previous = lx_error
          textid   = zcx_custom_error=>processing_failed.
  ENDTRY.
ENDMETHOD.
