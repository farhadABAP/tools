About & Extensibility

This is a static, client-side tool hosted on GitHub Pages. No data is sent to any server. Everything runs in your browser.

How to add a new tool:

  1. Add a new button in the .tabs div.
  2. Add a new div with class tool-panel and a unique ID.
  3. Add the ID to the switchTab() function in the script.
  4. Write your HTML/JS logic inside that panel.

Built-in Mock Tables

For demonstration, this tool has built-in metadata for: MARA, MARC, VBAK, VBAP, KNA1.
For other tables, the generator creates a generic but fully functional ABAP skeleton that you can easily adapt, or you can manually define the fields in the exported JSON.
